代码签名政策

ClipLink for Windows 经过代码签名，这样 Windows 可以显示发布者是谁，并在文件构建之后被改动时发出警告。本页说明发布版本如何构建和签名。

状态：代码签名正在准备中。当前的测试版安装程序尚未签名，所以 Windows SmartScreen 可能会发出警告。有签名的版本发布后，本页会随之更新。

发布版本如何产生

  • ClipLink 以 Apache License 2.0 开源。发布版本里的一切内容都在公开仓库中。
  • 发布文件由 GitHub Actions 根据该仓库中的源代码自动构建，没有任何手工构建或修改。
  • 构建出的文件随后提交签名，每一次签名请求都必须由维护者批准后才会签名。与仓库构建不符的请求不会被批准。
  • 只有 ClipLink 自己构建的程序会被签名：ClipLink 应用及其安装程序。随应用一起发布的第三方库保留其各自发布者的签名。
  • 签名后的文件发布在发布页面。

团队角色

  • 提交者和审核者：仓库所有者 Colour1205。
  • 批准者：仓库所有者 Colour1205。

更改通过拉取请求（pull request）进入主分支。如果有更多维护者加入，会在此列出。

隐私

  • ClipLink 不会向其开发者运营的任何服务器发送信息，也没有账号。
  • 除非用户明确要求，程序不会向其他联网系统传输任何信息。你复制的内容只会直接发送到你选择配对的设备。
  • 本网站没有 Cookie，也没有统计分析。页面加载时，你的浏览器会向 GitHub 的公开 API 查询最新版本，因此 GitHub 能看到这个请求。

反馈问题

如果你认为某个已签名的文件有问题，或发现了安全问题，请提交 issue。
