Questions

Does my clipboard go through a server?

No. Items go straight from one of your paired devices to another. ClipLink has no servers and no accounts.

Does it work away from my home network?

On the same network, devices find each other on their own. Elsewhere, you can pair by address, for example over a VPN such as Tailscale, as long as the devices can reach each other.

Why does my phone only sync when the app is open?

iOS and HarmonyOS don't let apps keep running in the background, so those phones catch up when you open ClipLink. Android can stay running if you turn that on in settings. Windows runs in the tray, so it syncs all the time.

Windows says "Windows protected your PC".

The beta installer isn't code-signed yet, so Windows SmartScreen warns about it. Choose More info, then Run anyway. Code signing for releases is being set up; see the code signing policy.

Is it free?

Yes. ClipLink is free and open source under the Apache 2.0 licence. The code is on GitHub.
