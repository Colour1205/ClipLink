# Images

Screenshots of the apps and the pictures used for the app stores, one folder per platform.
The [main README](../README.md) uses `windows/`, `ios/`, `android/` and `harmonyos/phone/`.

| Folder | What is in it |
| --- | --- |
| `windows/` | The Windows app |
| `ios/` | The iPhone app: the picture on the main README (`synced.webp`) and the App Store screenshots with sample content: four iPhone ones (`phone-1-synced.png`, `phone-2-devices.png`, `phone-3-me.png`, `phone-4-settings.png`) at 1320x2868, the 6.9-inch size, and three iPad ones (`ipad-1-synced.png`, `ipad-2-devices.png`, `ipad-3-me.png`) at 2048x2732, the 13-inch size |
| `android/` | The Android app: the Devices, Me, Settings and Synced screens, plus the pictures on the Google Play page (`icon-512.png`, `feature-graphic-1024x500.png` and the four `phone-*.png` screenshots at 1080x1920) |
| `harmonyos/phone/` | The HarmonyOS phone app, 1080x1920 |
| `harmonyos/tablet/` | The HarmonyOS tablet app, 1920x1280 |
